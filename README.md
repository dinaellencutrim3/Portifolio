# Portfólio — Dinaellen Cutrim

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript, apresentando meus projetos e informações de contato.

## Tecnologias utilizadas

- HTML5
- CSS3 (Grid, Flexbox, animações, gradientes)
- JavaScript (ES6+, Fetch API)

## Funcionalidades

- Design responsivo para diferentes tamanhos de tela
- Animações e efeitos visuais em CSS puro
- Cards de projetos com links diretos
- Integração com WhatsApp para contato
